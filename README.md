# 📈 Stock Data Dashboard  
**Analyzing Trading Volumes, Price Trends, and Market Insights**  

## 🔍 Project Overview  
This project presents a **Stock Market Data Dashboard**, built using **Microsoft Excel**, to visualize key stock performance metrics, including:  
✔ **Daily price range comparison across companies**  
✔ **Total trading volume and value calculations**  
✔ **Adjusted close price trends over time**  
✔ **Company-wise stock analysis with slicers for filtering**  

The dashboard provides a **dynamic and interactive way** to analyze stock data, helping users track performance and gain insights into trading trends.  

## 🛠 Tools & Technologies Used  
- 📊 **Microsoft Excel** – Primary tool for data analysis and dashboard creation  
- 🔄 **Pivot Tables** – Excel feature for summarizing and analyzing stock data  
- 📉 **Pivot Charts** – Excel feature for visualizing data insights dynamically  
- 🎛 **Slicers & Filters** – Excel feature for interactive data exploration  

## 📊 Key Insights & Features  
📍 **Samsung leads in daily price range fluctuations**, indicating high market activity.  
📊 **Amazon has the highest total volume traded**, reflecting strong investor interest.  
📈 **Stock trading volumes vary significantly by year**, with **2023 showing the highest activity**.  
📅 **Users can filter by company, date, and years** to explore historical trends interactively.
